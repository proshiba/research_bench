# 日本のレポーターから通報が上がっている索引の IP

> この表が言えるのは「**通報した人が日本に居る**」ことだけです。
> 攻撃先が日本であること、送信元が日本を狙っていることは**意味しません**。
> 日本に観測者や監視機器が多いというだけでも同じ数字になります。

| 項目 | 件数 |
| --- | --- |
| 通報が 1 件以上ある索引の IP | 816 |
| うち日本ぶんを数えた | 0 |
| **まだ数えていない（分からない）** | **816** |
| **日本からの通報があった** | **0** |
| うち索引がアクター名を付けている | **0** |

## 印

**消していません。**読む側が外して数え直せるように付けてあります。

| 印 | 意味 | 件数 |
| --- | --- | --- |
| hosting | 事業者の網（相乗りの可能性） | 0 |
| sample | 中身の無い通報が大半（見本アドレスの疑い） | 0 |
| tor | Tor 出口 | 0 |
| whitelisted | AbuseIPDB の除外一覧 | 0 |
| 踏み台の通報あり | **送信元自体が侵害されている可能性**。持ち主も被害者かもしれません | 0 |

## 制約

- **母集団は索引が持っている IP だけ**です。AbuseIPDB 全体ではありません
- 通報の窓は 365 日です
- 通報があるのに日本ぶんを数えていない IP が 816 件あります。これは「日本からの通報なし」ではなく**分からない**という意味です
- `reporterId` は数を数えるためだけに使い、値は保存していません
- 通報コメントの本文は保存していません。中身があったかどうかだけを数えています
- 対象 IP への接続・走査は行っていません。AbuseIPDB の公開情報だけです
